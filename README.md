# 五行石室 threesun

水晶手鏈同擺件網店示範，中英雙語，附以下占卜工具，每個結果都配返適合嘅水晶：

- 八字五行：排四柱、數五行、搵最弱嘅五行
- 星座：太陽星座同常見配搭水晶
- 生肖太歲：2026 丙午年同太歲嘅關係、三合六合貴人
- 塔羅：22 張大阿爾克那，抽三張（過去、現在、未來）
- 今日運勢：用日主同今日日柱五行推算
- 九宮擺位：方位五行加 2026 流年飛星

貨品、價錢同批次資料全部係示範例子。

## 檔案

- `index.html`：頁面結構
- `css/style.css`：樣式
- `js/data.js`：貨品、翻譯、星座、塔羅、飛星資料（改貨品同文字改呢度）
- `js/app.js`：計算同畫面邏輯

純靜態網站，可以直接放上 Cloudflare Pages 或 GitHub Pages。
